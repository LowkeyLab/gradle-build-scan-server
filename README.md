# Gradle Build Scan Server

A self-hosted server for receiving and viewing Gradle build scans.

## Documentation

- Hosted docs: https://lowkeylab.github.io/gradle-build-scan-server/
- Bazel workflows: https://lowkeylab.github.io/gradle-build-scan-server/bazel/

The full setup, Docker, and local development instructions now live in the Astro docs site under `docs/` so GitHub and GitHub Pages share one source of truth.
